# Structura

> Визуальный конструктор структуры проекта для Linux и Windows.

Structura помогает быстро собрать каркас нового проекта: выбрать шаблон, создать
папки и файлы, привести дерево в нужный вид и сохранить готовую структуру на диск.
Всё делается в компактном интерфейсе в стиле тёмной IDE — без ручного создания
десятков каталогов и пустых файлов.

## Возможности

- готовая структура Spring Boot или полностью пустой проект;
- открытие уже существующей папки с отображением всего её дерева;
- создание папок и файлов прямо внутри дерева;
- автоматическое расширение файла для выбранного языка;
- переименование на месте через `F2` или двойной клик;
- перенос элементов между папками мышью;
- защита от пустых имён, слешей, дубликатов и некорректного переноса;
- сохранение всей подготовленной структуры в выбранную папку;
- автономная desktop-версия — после установки отдельная Java не требуется.

Поддерживаемые расширения: Java, Kotlin, Python, JavaScript, TypeScript, Go,
C# и C++.

## Скачать и запустить

Готовые сборки находятся на странице
[Releases](../../releases/latest). Выберите архив для своей операционной системы,
распакуйте его в удобную папку и следуйте инструкции ниже.

### Linux

1. Скачайте архив сборки для Linux и распакуйте его.
2. Откройте распакованную папку `Structura`.
3. Запустите файл `bin/Structura`.

Если система не разрешает запуск, откройте терминал в папке приложения и выполните:

```bash
chmod +x bin/Structura
./bin/Structura
```

### Windows

1. Скачайте архив сборки для Windows и распакуйте его.
2. Откройте распакованную папку `Structura`.
3. Запустите находящийся в ней файл `Structura.exe`.

Устанавливать JDK, JavaFX или дополнительные библиотеки для готовой сборки не
нужно — необходимая среда уже находится внутри приложения.

> Сборки платформозависимы: архив для Linux не запустится на Windows, а архив
> для Windows — на Linux.

## Как пользоваться

1. Введите название будущего проекта.
2. Выберите шаблон и язык новых файлов.
3. Нажмите **«Создать структуру»**.
4. Добавляйте папки и файлы кнопками над деревом.
5. Переименовывайте элементы двойным кликом или клавишей `F2`.
6. Перетаскивайте элементы мышью в нужные папки.
7. Выберите папку назначения и нажмите **«Сохранить»**.

Если в дереве выбран файл, новый элемент появится рядом с ним. Если выбрана
папка — внутри неё. Новые элементы сразу получают временное уникальное имя и
переходят в режим редактирования.

### Работа с существующей папкой

Нажмите **«Открыть папку и показать дерево»** и выберите проект на диске.
Structura покажет находящиеся внутри папки и файлы. После этого дерево можно
редактировать как обычно: добавлять, переименовывать, переносить и удалять элементы.

Изменения применяются к диску только после нажатия **«Сохранить»** и дополнительного
подтверждения. Содержимое существующих файлов сохраняется. Элементы, удалённые из
дерева, после подтверждения также будут удалены из открытой папки.

## Горячие клавиши

| Действие | Сочетание |
|---|:---:|
| Создать папку | `Alt` + `P` |
| Создать файл | `Alt` + `F` |
| Переименовать | `F2` |
| Подтвердить новое имя | `Enter` |
| Отменить переименование | `Escape` |
| Удалить выбранный элемент | `Delete` |

## Сборка из исходников

Этот раздел нужен только разработчикам. Для обычного использования проще скачать
готовую версию из [Releases](../../releases/latest).

Для сборки потребуется полный **JDK 25**. Gradle отдельно устанавливать не нужно:
в репозитории находится Gradle Wrapper.

### Linux

Сначала клонируйте репозиторий или скачайте **Source code** со страницы релиза и
распакуйте архив. Затем откройте терминал в каталоге `Structura`:

```bash
chmod +x gradlew
./gradlew run
```

Создание автономной сборки:

```bash
./gradlew clean packageApp
```

Готовое приложение появится в `build/package/Structura`.

### Windows

Клонируйте репозиторий или скачайте и распакуйте **Source code**, затем откройте
PowerShell в каталоге `Structura`:

```powershell
gradlew.bat run
```

Создание автономной сборки:

```powershell
gradlew.bat clean packageApp
```

Результат также будет находиться в `build\package\Structura`.

## Технологии

- Java 25;
- JavaFX 25;
- FXML и CSS;
- Gradle Kotlin DSL;
- `jpackage` для автономных desktop-сборок.

## Важно знать

- Structura не изменяет файлы во время редактирования дерева. Они создаются только
  или изменяются после нажатия **«Сохранить»**.
- Проект нельзя сохранить поверх уже существующей одноимённой папки. Это защищает
  находящиеся в ней данные от случайной перезаписи.
- `jpackage` создаёт сборку только для текущей операционной системы. Windows-версию
  следует собирать на Windows, а Linux-версию — на Linux.
